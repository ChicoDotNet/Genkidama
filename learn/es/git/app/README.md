# ReleaseDesk

ReleaseDesk es el proyecto canónico del curso de Git de Genkidama Learn.

Su objetivo es mantener una pequeña bitácora de entregas sin depender de ningún lenguaje de programación. El valor del proyecto está en observar cómo evoluciona mediante commits, ramas, merges y recuperación.

## Estado

Versión inicial: `0.1`

## Archivos principales

- `README.md`: contexto del proyecto.
- `docs/plan.md`: alcance de la siguiente entrega.
- `CHANGELOG.md`: cambios publicados.

No inicialices Git dentro de esta carpeta mientras siga dentro del checkout de Genkidama. Copia `app/` a un directorio independiente como indica el README del curso.
