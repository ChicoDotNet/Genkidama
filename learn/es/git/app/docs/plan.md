# Plan de entrega 0.1

## Objetivo

Dejar una bitácora mínima que explique qué cambia en cada entrega y permita revisar la historia sin depender de copias como `final-v2-ahora-si`.

## Alcance

- documentar el propósito del proyecto;
- mantener un changelog legible;
- agregar una plantilla de incidentes en un incremento posterior.

## Fuera de alcance

ReleaseDesk no ejecuta código de negocio. Es un proyecto deliberadamente pequeño para que los cambios de Git sean fáciles de observar.
