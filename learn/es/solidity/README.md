# Curso de Solidity desde cero — FreelanceEscrow

Curso práctico en español para aprender Solidity construyendo un contrato de escrow para proyectos freelance. La aplicación canónica conserva cuatro capacidades centrales: depósito del cliente, registro de entrega, liberación del pago y reembolso.

## Estado

Piloto en construcción. El objetivo es terminar con un contrato probado que el alumno pueda ejecutar, modificar, explicar y defender en una entrevista junior, sin prometer empleo ni presentar Solidity como un mercado masivo.

## Aplicación final

`FreelanceEscrow` modela un acuerdo simple entre cliente y freelancer. El curso usa la máquina de estados del contrato para enseñar tipos, funciones, visibilidad, errores, eventos, Ether, pruebas, seguridad y diseño de contratos.

## Prerrequisitos

No necesitas conocer Solidity. Sí necesitas comodidad básica usando una terminal y un editor. El curso no enseña especulación, trading ni lanzamiento de tokens.

## Ruta inicial

1. Ejecutar y entender un contrato mínimo de escrow.
2. Modelar participantes y estados.
3. Recibir un depósito y validar transiciones.
4. Registrar entrega, liberar o reembolsar con pruebas.

## Seguridad

Los ejemplos usan únicamente redes locales de desarrollo y valores ficticios. Antes de desplegar software que custodie valor real se requiere revisión de seguridad profesional adicional.
