# Checkpoint 04 — Diagnóstico y entrega segura

Sin receta paso a paso:

1. prepara una carpeta con cotizaciones válidas y al menos un archivo inválido;
2. genera un diagnóstico que permita explicar el estado sin exponer nombres ni descripciones;
3. crea un backup no destructivo en otra carpeta y demuestra que el origen no cambió;
4. reproduce una falla, reduce el caso a una prueba y documenta qué señal te permitió localizarla;
5. publica QuoteDesk para `win-x64` y distingue claramente artefacto publicable de instalador.

La evidencia debe incluir tests verdes y un backup verificable.

Después de intentarlo: [solución de referencia](../solutions/checkpoint-04-solution.md).
