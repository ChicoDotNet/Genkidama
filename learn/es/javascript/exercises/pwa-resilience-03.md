# Ejercicio integrado 03 — Persistencia y experiencia offline

Modifica Kanban Local sin receta paso a paso para que el mensaje inicial diferencie el origen de los datos: persistencia estructurada o compatibilidad local. Conserva el dominio libre de APIs del navegador y añade una prueba automatizada de la capa de persistencia para un escenario de recuperación.

Mantén `npm run check`, `npm test` y `npm run smoke` verdes. Después de una primera carga online, verifica manualmente que la app shell pueda abrirse en modo offline.

Explica brevemente por qué IndexedDB, Cache Storage y el manifest resuelven problemas distintos.
