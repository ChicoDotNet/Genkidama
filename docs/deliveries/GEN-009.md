# GEN-009: StandardEvent and Notification Pipeline

## Goal

Add the first reusable event and notification foundation for generated Genkidama applications.

## Scope

- Add `Genkidama.Events`.
- Add `IGenkidamaEvent`.
- Add `StandardEvent`.
- Add event handler contract.
- Add event publisher contract.
- Add event publisher.
- Add `StandardNotification`.
- Add notification channel contract.
- Add in-memory notification channel.
- Add MSTest coverage for events, publisher and notifications.
- Include events projects in `Genkidama.slnx`.

## Acceptance criteria

- Events can be represented with stable identity, name and timestamp.
- Event handlers return `StandardResult`.
- Event publisher runs handlers in sequence.
- Event publisher preserves the first failed handler result.
- Notifications can be sent through a standard channel abstraction.
- The delivery does not depend on external messaging, queueing or notification packages.
