# GEN-019: Add Block Generator

## Goal

Add the first generator for reusable application blocks in generated Genkidama applications.

## Scope

- Add generation options.
- Add block name normalization.
- Add block source template generation.
- Add block runner.
- Route `genkidama add block <Name>` through the CLI.
- Add MSTest coverage for name normalization.
- Add MSTest coverage for block template generation.
- Add MSTest coverage for runner execution.

## Acceptance criteria

- CLI accepts `genkidama add block <Name>`.
- Block names are normalized to PascalCase.
- The generated block includes a descriptor source file.
- The generated block includes a starter source file.
- The generated block includes a registration source file.
- The generated block includes a README.
- The app name is inferred from the current directory name.
- Existing commands remain unchanged.
