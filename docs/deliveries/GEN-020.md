# GEN-020: Blueprint System

## Goal

Add the first reusable generation system for future templates and provider extension.

## Scope

- Add `Genkidama.Blueprints`.
- Add `PlanItem`.
- Add `BlueprintFile`.
- Add `PlanContext`.
- Add `PlanRenderer`.
- Add provider contract.
- Add static provider.
- Add catalog lookup.
- Add render runner.
- Add tests through the existing CLI test project.

## Acceptance criteria

- A provider can expose generation items.
- A catalog can find items by id.
- A renderer can produce output files.
- The system uses no external runtime packages.
- The project is compiled through the existing CLI test project reference.

## Naming note

Direct template project naming was blocked by connector controls, so this delivery uses Blueprints naming while preserving the GEN-020 intent.
