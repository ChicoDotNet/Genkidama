# GEN-004: HTTP Layer

## Goal

Add the first reusable HTTP foundation for Genkidama applications.

## Scope

- Add `Genkidama.Http`.
- Add `HttpQueryAttribute`.
- Add stable HTTP header names.
- Add trace identifier helper.
- Add trace identifier middleware.
- Add application builder extension for middleware registration.
- Add MSTest coverage for attribute, trace helper and middleware behavior.
- Include HTTP projects in `Genkidama.slnx`.

## Acceptance criteria

- HTTP query binding can be marked with `[HttpQuery]`.
- The trace identifier helper reuses `HttpContext.TraceIdentifier` when present.
- The middleware writes a stable Genkidama trace header.
- The middleware can be registered with `UseGenkidamaTraceIdentifier()`.
- The HTTP package uses ASP.NET Core through framework reference only.
