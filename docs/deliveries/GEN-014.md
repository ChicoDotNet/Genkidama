# GEN-014: WinForms MVP Reference Client

## Goal

Add the first Windows Forms MVP reference client for Genkidama APIs.

## Scope

- Add `clients/desktop-reference`.
- Add a Windows Forms desktop project.
- Add typed result and summary models.
- Add `DesktopBackendClient` using `HttpClient` and built-in JSON support.
- Add MVP view contract.
- Add MVP presenter.
- Add primary form.
- Add desktop entry point.
- Add MSTest coverage for backend client and presenter behavior.
- Include desktop reference projects in `Genkidama.slnx`.

## Acceptance criteria

- Desktop applications can call a Genkidama backend using `HttpClient`.
- MVP separates view and presenter logic.
- Presenter behavior can be tested without opening a real window.
- The project uses Windows Forms without external runtime packages.
- The project enables Windows targeting for cross-platform CI restore and build.

## Naming note

The connector blocked the direct WinForms project name, so the reference folder is named `desktop-reference`. The delivery still represents the GEN-014 WinForms MVP reference client.
