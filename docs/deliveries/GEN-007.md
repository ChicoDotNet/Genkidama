# GEN-007: Command and Query Pipeline

## Goal

Add the first reusable Command and Query pipeline for generated Genkidama applications.

## Scope

- Add `Genkidama.Application`.
- Add `IGenkidamaCommand<TResponse>`.
- Add `IGenkidamaQuery<TResponse>`.
- Add command and query handler contracts.
- Add pipeline delegate contract.
- Add pipeline behavior contract.
- Add ordered pipeline execution.
- Add command dispatcher.
- Add query dispatcher.
- Add MSTest coverage for pipeline and dispatchers.
- Include application projects in `Genkidama.slnx`.

## Acceptance criteria

- Commands and queries can be modeled separately.
- Handlers return `StandardResult<TResponse>`.
- Pipeline behaviors can wrap handler execution in order.
- Command dispatcher sends a command through the pipeline.
- Query dispatcher sends a query through the pipeline.
- The delivery does not depend on MediatR or external DI packages.
