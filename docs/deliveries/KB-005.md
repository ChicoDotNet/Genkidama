# KB-005

## Goal

Make the Design Patterns catalog easier to discover, navigate, and understand as a connected design vocabulary rather than a flat list of isolated patterns.

## Scope

- Move the detailed pattern-family listing out of the repository root README.
- Add `wiki/README.md` as the stable navigation entry point for all current pattern pages.
- Add a Mermaid relationship map covering every current pattern and selected common collaborations, alternatives, and conceptual relatives.
- Add short pattern constellations that explain combinations readers are likely to encounter in real designs.
- Keep the root README concise and link directly to the catalog and relationship map.

## Non-goals

- Do not fill every existing placeholder pattern page in this delivery.
- Do not change pattern implementations or generated application behavior.
- Do not imply that a relationship in the diagram is a mandatory dependency.

## Validation

- Every catalog link targets an existing file under `wiki/`.
- The Mermaid diagram uses GitHub-supported flowchart syntax and avoids presentation-specific styling.
- The root README no longer duplicates the full pattern list.
- Runtime code, Genkidama Learn courses, and application behavior remain unchanged.
