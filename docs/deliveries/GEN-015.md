# GEN-015: MAUI MVVM Reference Client

## Goal

Add the first MAUI MVVM reference client for Genkidama APIs.

## Scope

- Add `clients/maui-reference`.
- Add portable `Genkidama.MauiReference.Core` project.
- Add `ObservableObject`.
- Add `AsyncCommand`.
- Add typed result and summary models.
- Add `MauiBackendClient` using `HttpClient` and built-in JSON support.
- Add `MainViewModel` with bindable state and refresh behavior.
- Add source-only MAUI `App`, `MainPage` and bootstrap files.
- Add MSTest coverage for command, backend client and view model behavior.
- Include MAUI core projects in `Genkidama.slnx`.

## Acceptance criteria

- MAUI applications can follow a clear MVVM reference pattern.
- MVVM logic is testable without a MAUI workload.
- The reference uses .NET built-in primitives and no external MVVM packages.
- The compiled core remains cross-platform for CI.
- MAUI app files remain source-only until a dedicated MAUI pipeline exists.
