# GEN-008: StandardJob and Background Processing

## Goal

Add the first reusable job and background processing foundation for generated Genkidama applications.

## Scope

- Add `Genkidama.Jobs`.
- Add `StandardJobStatus`.
- Add `StandardJob`.
- Add `IGenkidamaJob<TResponse>`.
- Add job handler contract.
- Add background job queue contract.
- Add in-memory background job queue.
- Add job dispatcher.
- Add MSTest coverage for job status, queue and dispatcher behavior.
- Include jobs projects in `Genkidama.slnx`.

## Acceptance criteria

- Jobs can be represented with stable identity, name, timestamp and status.
- Queued jobs can move to running status when dequeued.
- Empty queue dequeue returns a standard failure result.
- Job handlers return `StandardResult<TResponse>`.
- The delivery does not depend on Hangfire, Quartz or external worker packages.
