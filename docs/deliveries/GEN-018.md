# GEN-018: Add Feature Generator

## Goal

Add the first `genkidama add feature` vertical slice generator for generated Genkidama applications.

## Scope

- Add `AddFeatureOptions`.
- Add feature name normalization.
- Add feature source template generation.
- Add `GenkidamaAddFeatureCommand`.
- Route `genkidama add feature <FeatureName>` through the CLI.
- Update CLI help text.
- Add MSTest coverage for name normalization.
- Add MSTest coverage for feature template generation.
- Add MSTest coverage for command execution.
- Add MSTest coverage for router behavior.

## Acceptance criteria

- CLI accepts `genkidama add feature <FeatureName>`.
- Feature names are normalized to PascalCase.
- The generated slice includes a contract DTO.
- The generated slice includes command and query source files.
- The generated slice includes command and query handler source files.
- The generated slice includes a feature README.
- The app name is inferred from the current directory name.
- Existing `new`, `add entity`, `add enum` and `--version` behavior remains unchanged.

## Design note

This delivery creates source files only. Handler bodies stay intentionally small until template system and module generation can provide richer wiring rules.
