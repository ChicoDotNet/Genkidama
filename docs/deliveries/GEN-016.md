# GEN-016: Add Entity Generator

## Goal

Add the first `genkidama add entity` generator for generated Genkidama applications.

## Scope

- Add `AddEntityOptions`.
- Add entity name normalization.
- Add entity file template generation.
- Add `GenkidamaAddEntityCommand`.
- Route `genkidama add entity <EntityName>` through the CLI.
- Update CLI help text.
- Add MSTest coverage for name normalization.
- Add MSTest coverage for template generation.
- Add MSTest coverage for command execution.
- Add MSTest coverage for router behavior.

## Acceptance criteria

- CLI accepts `genkidama add entity <EntityName>`.
- Entity names are normalized to PascalCase.
- The generated entity is written under `src/{AppName}.Domain/Entities`.
- The app name is inferred from the current directory name.
- Existing `new` and `--version` behavior remains unchanged.
