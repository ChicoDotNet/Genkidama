# GEN-001: CLI Bootstrap

## Goal

Create the first usable Genkidama CLI skeleton with tests from the beginning.

## Scope

- Add repository build defaults.
- Add CLI project.
- Add MSTest project.
- Support `genkidama --version`.
- Keep all public and internal members documented in English.

## Acceptance criteria

- `dotnet build` succeeds.
- `dotnet test` succeeds.
- Coverage tooling is present.
- CLI returns a deterministic version string.
