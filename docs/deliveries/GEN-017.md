# GEN-017: Add Enum Generator

## Goal

Add the first `genkidama add enum` generator and enum seed support for generated Genkidama applications.

## Scope

- Add `AddEnumOptions`.
- Add enum name normalization.
- Add domain enum source template generation.
- Add persistence enum seed JSON generation.
- Add `GenkidamaAddEnumCommand`.
- Route `genkidama add enum <EnumName>` through the CLI.
- Allow optional enum values after the enum name.
- Update CLI help text.
- Add MSTest coverage for name normalization.
- Add MSTest coverage for enum template generation.
- Add MSTest coverage for seed template generation.
- Add MSTest coverage for command execution.
- Add MSTest coverage for router behavior.

## Acceptance criteria

- CLI accepts `genkidama add enum <EnumName>`.
- CLI accepts optional values after the enum name.
- Enum names and values are normalized to PascalCase.
- The generated enum is written under `src/{AppName}.Domain/Enums`.
- The generated seed is written under `src/{AppName}.Persistence/Seeds/Enums`.
- The app name is inferred from the current directory name.
- Existing `new`, `add entity` and `--version` behavior remains unchanged.
