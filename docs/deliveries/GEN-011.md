# GEN-011: React Reference Client

## Goal

Add the first React reference client for Genkidama APIs that return `StandardResult<TValue>` and `StandardCollectionResult<TItem>`.

## Scope

- Add `clients/react-reference`.
- Add TypeScript contracts for `StandardProblem`.
- Add TypeScript contracts for `StandardResult<TValue>`.
- Add TypeScript contracts for `StandardQuery`.
- Add TypeScript contracts for `StandardCollectionResult<TItem>`.
- Add a fetch-based `StandardApiClient`.
- Add a React hook for read operations.
- Add a reference dashboard component.
- Add README usage guidance.

## Acceptance criteria

- React consumers can model Genkidama standard API responses.
- Client code uses the platform Fetch API.
- The reference client does not add runtime dependencies to the .NET core projects.
- The client is copyable by future template deliveries.
- The delivery avoids publishing or packaging decisions before the template system is ready.

## Testing note

This delivery adds reference TypeScript and React source files only. It intentionally does not add a Node build pipeline or package manager lockfile yet, to avoid introducing frontend tooling policy before the template system delivery.
