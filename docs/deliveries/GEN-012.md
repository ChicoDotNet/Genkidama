# GEN-012: Angular Reference Client

## Goal

Add the first Angular reference client for Genkidama APIs that return standard result shapes.

## Scope

- Add `clients/angular-reference`.
- Add TypeScript contracts for standard API responses.
- Add Angular `HttpClient` wrapper.
- Add query state helper.
- Add standalone reference dashboard component.
- Add README usage guidance.

## Acceptance criteria

- Angular consumers can model standard Genkidama API responses.
- Client code uses Angular `HttpClient` and Observables.
- The reference client stays outside the .NET core projects.
- The client is copyable by future template deliveries.
- The delivery avoids package publishing decisions before the template system is ready.

## Testing note

This delivery adds reference TypeScript and Angular source files only. It does not add a Node build pipeline or package manager lockfile yet.
