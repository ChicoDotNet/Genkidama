# GEN-005: Data Provider Factory

## Goal

Add the first reusable data provider foundation for Genkidama applications.

## Scope

- Add `Genkidama.Data`.
- Add the approved core database providers: MariaDB, SQLite, SQL Server and PostgreSQL.
- Add standard schema names: Audit, Business, Enum, Security and Utility.
- Add data options.
- Add a data descriptor.
- Add a data factory contract.
- Add the default data factory.
- Add MSTest coverage for providers and factory behavior.
- Include data projects in `Genkidama.slnx`.

## Acceptance criteria

- Core provider choices are constrained to the approved four providers.
- Standard schema names are available as constants.
- A valid SQLite option creates a data descriptor.
- An empty connection string returns a standard failure result.
- The package remains provider-agnostic and avoids concrete EF provider dependencies in this delivery.
