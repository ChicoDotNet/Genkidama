# GEN-002: New Solution Generator

## Goal

Create the first usable `genkidama new` solution generator.

## Scope

- Add a generated file model.
- Add a minimal backend solution template.
- Generate Api, Contracts, Application, Domain and Persistence projects.
- Add command routing for `genkidama new {AppName}`.
- Add MSTest coverage for the template and command.

## Acceptance criteria

- `genkidama new SampleApp` writes a generated folder.
- Generated output includes README.md.
- Generated output includes the five baseline backend projects.
- Existing `genkidama --version` behavior remains stable.
