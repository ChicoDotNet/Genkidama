# GEN-006: Repository and Unit of Work

## Goal

Add the first reusable Repository and Unit of Work contracts for generated Genkidama applications.

## Scope

- Add `IGenkidamaEntity<TKey>`.
- Add `IGenkidamaRepository<TEntity, TKey>`.
- Add `IGenkidamaUnitOfWork`.
- Add in-memory repository implementation for tests and generated samples.
- Add in-memory unit of work implementation for tests and generated samples.
- Add MSTest coverage for repository behavior.
- Add MSTest coverage for unit of work behavior.

## Acceptance criteria

- Entities can expose a stable typed identifier.
- Repositories can find, list, add and remove entities.
- Repository operations use `StandardResult` and `StandardCollectionResult`.
- Unit of Work saves changes through a standard result.
- The delivery does not require EF or concrete database providers.
