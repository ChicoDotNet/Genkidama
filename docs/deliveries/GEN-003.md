# GEN-003: Standard Contracts

## Goal

Add the first reusable contract package for Genkidama applications.

## Scope

- Add `Genkidama.Contracts`.
- Add `StandardProblem`.
- Add `StandardResult`.
- Add typed `StandardResult<TValue>`.
- Add `StandardQuery`.
- Add `StandardCollectionResult<TItem>`.
- Add MSTest coverage for the core contracts.
- Include contracts projects in `Genkidama.slnx`.

## Acceptance criteria

- Standard success and failure results are available.
- Standard validation problems are available.
- Standard query pagination exposes deterministic skip calculation.
- Standard collection results preserve items, total count and query metadata.
- Contract code remains dependency-free.
