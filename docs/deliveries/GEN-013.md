# GEN-013: Console Reference Client

## Goal

Add the first .NET console reference client and typed backend client for Genkidama APIs.

## Scope

- Add `clients/console-reference`.
- Add `Genkidama.ConsoleReference` console project.
- Add deserializable API result model.
- Add deserializable API collection model.
- Add backend options.
- Add typed `ConsoleBackendClient`.
- Add reference `Program` entry point.
- Add MSTest coverage for backend options and typed backend calls.
- Include console reference projects in `Genkidama.slnx`.

## Acceptance criteria

- Console applications can call a Genkidama backend using `HttpClient`.
- Typed result responses can be read from standard API JSON.
- HTTP failures are mapped to a typed failed result.
- The client uses .NET built-in HTTP and JSON functionality.
- The delivery does not add external packages beyond existing MSTest usage for tests.
