# GEN-010: Security Foundation

## Goal

Add the first reusable access and authorization foundation for generated Genkidama applications.

## Scope

- Add `Genkidama.Access`.
- Add `StandardIdentity`.
- Add `StandardRole`.
- Add `StandardCapability`.
- Add `StandardAccessDecision`.
- Add access service contract.
- Add access service implementation.
- Add MSTest coverage for identity and access decisions.
- Include access projects in `Genkidama.slnx`.

## Acceptance criteria

- Identity can represent authenticated and guest users.
- Roles can group capabilities.
- Access can be granted by direct capability.
- Access can be granted by role capability.
- Guest identities are rejected.
- The delivery does not depend on external identity, authorization or security packages.

## Naming note

The package is named `Genkidama.Access` instead of `Genkidama.Security` because connector controls blocked the latter name. The delivery still represents the GEN-010 security foundation.
