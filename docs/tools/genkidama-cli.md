# Genkidama CLI Tool

GEN-022 packages the CLI as a .NET tool.

## Package identity

- Package id: `Genkidama.Cli`
- Tool command: `genkidama`
- Version: `0.1.0-alpha.22`

## Local workflow

Build, test and pack through the repository CI workflow. The package is written under `artifacts/packages` during CI validation.

Publishing to a public or private NuGet feed is intentionally outside this delivery.
