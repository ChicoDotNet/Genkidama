# Design Principles

This section captures the philosophy and design principles that should guide Genkidama architecture, blueprints, CLI behavior and generated applications.

## Current references

- `design-philosophy.md`: the core philosophy behind Genkidama.
- `generator-principles.md`: principles for CLI and blueprint generation.
- `application-principles.md`: principles for generated applications.

## Maintenance rules

- Principles should be stable enough to guide multiple deliveries.
- Principles should be practical enough to influence code, templates and documentation.
- A principle that cannot affect a decision should be rewritten or removed.
- New principles should connect to architecture decisions when they change behavior.
