# Engineering Standards Index

This section consolidates the standards that govern Genkidama deliveries and generated applications.

## Source documents

- `docs/engineering-standards.md`: original engineering standards created during the Engineering Core pod.
- `docs/testing.md`: testing guidance and CI expectations.
- `docs/roadmap.md`: delivery sequencing and definition of done.

## Consolidated standards

- `consolidated-engineering-standards.md`: canonical summary of the active standards.
- `delivery-checklist.md`: checklist used before opening or merging delivery pull requests.

## Maintenance rules

- Keep source code identifiers and XML documentation in English.
- Keep generated user-facing text ready for localization.
- Update this index when a new standard becomes authoritative.
- Prefer small, testable rules over broad principles that cannot be checked.
