# Genkidama Knowledge Base

The Knowledge Base is the source of truth for the engineering standards, architecture guidance, skill standards and educational material that should guide generated applications.

The desired flow is:

```text
Knowledge Base -> Blueprints -> CLI -> Generated Applications
```

Generated code should follow the Knowledge Base. The CLI and blueprints should not become the primary place where architectural intent is hidden.

## Sections

- `standards/`: consolidated engineering standards and delivery checklists.
- `architecture/`: reference architecture and architectural decisions.
- `principles/`: design philosophy and guiding principles.
- `skills/`: language, platform and client skill standards.
- `catalog/`: educational examples and design pattern explanations.
- `release/`: packaging, release and operational playbooks.
